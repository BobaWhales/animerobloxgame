# +1 Loot for Anime

A Roblox (Luau) anime spin on *+1 Loot to Forge*: slay monsters, loot ore, forge a stronger blade, roll a Race.

- **Play right away:** open `build/PlusOneLootForAnime.rbxlx` in Roblox Studio.
- **Copy and paste into your own place:** every script is in `src/` (see [SETUP.md](SETUP.md) for where each one goes).
- **UI:** put `UIPackPlus` in ReplicatedStorage and it skins the whole UI (see SETUP.md).

Rojo users: `rojo build default.project.json -o game.rbxlx` or `rojo serve`.
